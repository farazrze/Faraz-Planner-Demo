# Personal Planner App

A personal productivity application designed to help users organize their daily plans, track goals, manage notes, and stay on schedule with timely notifications.

## Features

- **Goal Management** — Create and track personal goals.
- **Daily Planning** — Organize daily tasks and plans efficiently.
- **Notifications & Reminders** — Receive notifications to stay on track.
- **Notes** — Write and manage personal notes in one place.
- **Productivity & Organization** — Keep daily activities structured and accessible.
